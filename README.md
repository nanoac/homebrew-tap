# nanoac/homebrew-tap

Homebrew tap for [MicRouter](https://github.com/nanoac/mic-router).

## Install Menu Bar App (Recommended)

```bash
brew install --cask nanoac/tap/mic-router
```

> Note: Since the app is currently ad-hoc signed, you can pass `--no-quarantine` if you want to skip Gatekeeper's first-launch prompt.

## Install CLI (Geek Mode)

```bash
brew install nanoac/tap/mic-router
```
